# AI client glyphs

Monochrome brand glyphs from [Simple Icons](https://simpleicons.org) v16.33.0 (CC0 1.0),
used only to identify the AI clients bbdump can be connected to. The brands and logos
belong to their respective owners.

Clients whose owners asked Simple Icons to remove their logo (OpenAI, Visual Studio Code)
are not bundled: when those apps are installed, bbdump shows the app's own icon, read
from the system at runtime (`mcp-client-icons` IPC); otherwise a neutral initial.
