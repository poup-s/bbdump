# bbdump Landing Page

This directory contains the GitHub Pages landing page for bbdump.

## 🎨 Preview

Visit the live site at: `https://YOUR_USERNAME.github.io/bbdump`

## 📁 Structure

- `index.html` - Main landing page with modern design
- `assets/css/style.css` - Comprehensive styles with animations
- `assets/js/main.js` - Interactive JavaScript features
- `assets/images/` - Screenshots and media assets

## ✨ Features

- Modern, minimalist design
- Smooth animations and transitions
- Fully responsive (mobile, tablet, desktop)
- Interactive elements
- Animated gradient text
- Parallax effects
- Click-to-copy code blocks
- Intersection Observer animations

## 🚀 Quick Start

1. Replace `YOUR_USERNAME` in `index.html` with your GitHub username
2. Add screenshots to `assets/images/`
3. Push to GitHub
4. Enable GitHub Pages in repository settings (Settings > Pages)
5. Select `main` branch and `/docs` folder
6. Visit your site!

## 📖 Full Documentation

See `GITHUB_PAGES_SETUP.md` for detailed setup instructions and customization options.

## 🎯 Built With

- Vanilla JavaScript (no frameworks)
- Modern CSS with custom properties
- Google Fonts (Inter, JetBrains Mono)
- Intersection Observer API
- CSS Grid & Flexbox

## 💡 Customization

All styles can be customized via CSS variables in `style.css`:

```css
:root {
    --color-primary: #000000;
    --color-accent: #3b82f6;
    /* ... more variables */
}
```
